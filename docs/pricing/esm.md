## 3. 공식 (pre_discount)

```
G  = 원가(A) × C + E    (E=0)
I  = G × H
L  = I × (1 - J)
N  = I × 16.5%          ← 마켓수수료 (pre_discount, 등록가 기준)
M  = E = 0원
O  = L - M - N - 배송비흡수
S  = O - 원가(A)
V% = S / L × 100
```

**coef 계산:**
```
A타입 (J=2%):  coef = (1-0.02)×1 - 0.165 = 0.815
B타입 (J=61%): coef = (1-0.61)×1 - 0.165 = 0.225
```

**H 점근값 (최저 수익 분기점):**
```
최저가(A타입):  H_asymptote = 1 / (1.12 × 0.815) ≈ 1.097
일반/광고(B타입): H_asymptote = 1 / (1.5 × 0.225) ≈ 2.963
```

**최저가전략 H 역산 (A타입):**
```
H_raw = (target_S + 원가) / (G × 0.815)
```

**일반/광고전략 H 역산 (V% 기준):**
```
H_raw = 원가 / (G × (coef - target_V × (1-J)))
```
