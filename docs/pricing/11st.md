## 3. 공식 (pre_discount)

```
G  = 원가(A) × C + E
I  = G × H
L  = I × (1 - 0.50)       ← J=50% 고정
N  = I × 17.5%            ← 마켓수수료 (pre_discount, 등록가 기준)
M  = E = 120원
O  = L - M - N
S  = O - 원가(A)
V% = S / L × 100

coef(pre) = (1 - J)(1 - P) - fee = 0.5×1 - 0.175 = 0.325
```

**최저가전략 H 역산:**
```
H_raw = (target_S + 120 + 원가) / (G × 0.325)
```
