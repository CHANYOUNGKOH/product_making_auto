## 2. 자체 쿠폰 정책 (J — 가격대별 할인율)

도매가(원가 A) 기준 4단계. **위탁주문가 이상 상품에만 쿠폰 발행.**

| 단계 | 도매가(원가) 구간 | 쿠폰 할인율 J |
|------|----------------|------------|
| 1 | ≤ 5,000원 | 35% |
| 2 | 5,001 ~ 30,000원 | 28% |
| 3 | 30,001 ~ 100,000원 | 18% |
| 4 | > 100,000원 | 10% |

### 고도몰 어드민 쿠폰 등록가 기준 설정

도매가 기준 쿠폰은 고도몰 내부에서 **등록가(I) 구간**으로 설정해야 한다.  
전략마다 같은 도매가라도 등록가가 다르므로, 세 전략 중 가장 높은 I(광고전략 기준)를 상한선으로 사용한다.

| 쿠폰 할인율 | 도매가 구간 | 등록가 범위 (광고전략 기준) | **고도몰 설정 기준** |
|-----------|------------|------------------------|-----------------|
| 35% | ≤ 5,000원 | 최대 9,970원 | **등록가 10,000원 이하** |
| 28% | 5,001~30,000원 | 최대 50,460원 | **등록가 50,000원 이하** |
| 18% | 30,001~100,000원 | 최대 142,550원 | **등록가 140,000원 이하** |
| 10% | > 100,000원 | 129,050원~ | **등록가 140,001원 이상** |

> **주의:** 원가 경계점(5,001 / 30,001 / 100,001원) 직후 제품은 J 단계가 낮아져 등록가도 낮아진다.  
> 경계 근처에서 ±1단계 쿠폰 오차 가능하나 금액 영향 미미.

### 전략별 등록가(I) 구간 상세

| J | 도매가 구간 | 최저가전략 I | 일반판매전략 I | 광고전략 I |
|---|-----------|------------|-------------|---------|
| 35% | 50~5,000 | 170~8,100 | 240~9,590 | 240~9,970 |
| 28% | 5,001~30,000 | 7,320~43,480 | 8,390~48,660 | 8,690~50,460 |
| 18% | 30,001~100,000 | 38,200~127,180 | 41,450~135,050 | 43,250~142,550 |
| 10% | >100,000 | 115,870~579,100 | 121,550~607,550 | 129,050~645,050 |

## 4. 공식 (post_discount)

```
G  = 원가(A) × C + E
I  = G × H
L  = I × (1 - J)          ← J는 도매가 구간별 쿠폰 할인율
N  = L × 4%               ← 마켓수수료 (post_discount)
M  = E = 50원             ← 쿠폰 정산액
O  = L - M - N
S  = O - 원가(A)          ← 영업이익
V% = S / L × 100          ← 매출대비 영업이익률
```

**최저가전략 H 역산:**
```
coef = (1 - J) × (1 - 0.04)
H_raw = (target_S + E + 원가) / (G × coef)
H = ceil(H_raw, 3자리)    ← 올림으로 S ≥ 0 보장
```

**일반/광고전략 H 역산:**
```
coef_v = (1 - J) × (1 - 0.04 - V%)
H_raw  = (E + 원가) / (G × coef_v)
H = round(H_raw, 2자리)
```
