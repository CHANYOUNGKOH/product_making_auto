## 3. 공식 (post_discount)

```
G  = 원가(A) × C + E
I  = G × H
L  = I × (1 - 0.50)       ← J=50% 고정
N  = L × 6.5%             ← 마켓수수료 (post_discount)
Q  = L × 15%              ← 스마일캐시
M  = E = 100원
O  = L - M - N - Q
S  = O - 원가(A)
V% = S / L × 100

coef = (1 - 0.50) × (1 - 0.065 - 0.15) = 0.3925
```

**최저가전략 H 역산:**
```
H_raw = (target_S + 100 + 원가) / (G × 0.3925)
```

**점근 H (coef 기반):**
```
H_asymptote ≈ 1 / (C × coef) = 1 / (1.12 × 0.3925) ≈ 2.274
```
