### 폴더명 조립 (40 byte 이내 엑셀 LENB)

기본형: `{날짜 6자리}_{마켓코드}_할{할인값}_배{배송비}`

예: `260117_스스A1-0_할50_배3000`

- 날짜: 솔루션 파일명의 8자리(`20260117`) → 앞 2자리 제거하여 6자리로 축약
- 마켓코드: 솔루션 파일명의 두 번째 `_` 토큰 (`스스A1-0`, `옥션A2-3` 등)
- 할인값: 가공엑셀 `판매자 부담 할인` 컬럼 → `0.5` → `50`, `50%` → `50` 로 정규화
- 배송비: 가공엑셀 `배송비` 컬럼 → 쉼표 제거
- `_기본카테고리` 파일 포함 시 접두사 `이셀카테_` 추가 + 지마켓→지켓 축약
- 40 byte 초과 시 끝에서 자름 (한글 2byte, 영문/숫자 1byte)

**마켓별 동작 차이:** 스스/옥션/지마켓/11번가/기타 모두 위 로직으로 통일 (구현 분기되어 있지만 결과 동일).

### 옵션 포맷 (이셀러스 규격)
- 독립형: `옵션명*옵션값**추가금*수량*노출(Y/N)*이미지URL*판매자관리코드`
- 조합형: `옵션명1의 옵션값*옵션명2의 옵션값**추가금*수량*노출*이미지URL*판매자관리코드*용량`

### 가격 보정 — 기본 (`_correct_esellers_option_price`)
`config.option_price_rule != "none"` 이고 가공엑셀 `마켓판매가격` 있을 때 적용:

1. 각 옵션 라인에서 `**` 뒤 첫 `*` 앞 숫자 = 추가금 추출
2. 음수 → 0 으로
3. `max_delta = OptionPriceCorrector.calculate_max_delta(market_price)` 초과 시 제한
4. `rounding_unit` 으로 내림
5. 양수 옵션 0개면 첫 옵션 0원으로 강제
6. 양수 1개면 max_delta로 고정
7. 양수 2개 이상이면 최대값 기준 비율 스케일링

### 가격 보정 — 11번가 전용 2단계
`detected_market == "11번가"` 인 경우 **2-pass**:
1. **`_correct_11st_option_price`** — 각 옵션 추가금 × 2 (max_delta 제한)
2. 판매가 50% 인하 후 `price_diff = 원가 - 신가`
3. **`_apply_11st_option_shift`** — 모든 옵션 추가금 += `price_diff` 후 rounding_unit 내림 (`■대량단가` 라인은 제외, 0원 유지)

## 고도몰과의 공통 로직

- **alt 주입**: `seo_alt_injector.inject_alt_into_html(html, 상품코드)` 동일 적용 (ST2_JSON 기반)
- **`convert_origin`**: 원산지 변환 동일 (국산/해외/도시 분기)
- **OptionPriceCorrector**: 옵션 추가금 상한/내림 보정 공통 로직 (`Upload_Mapper/rules/option_price_correction.py`)
- **상품명 ST4 소스**: 동일 (`ST4_최종결과`)
- **키워드 enrichment 합치기**: 고도몰 `search_word` 와 이셀러스 `검색어(태그)` 정책 동일 구조
