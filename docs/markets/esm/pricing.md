## 2. 타입 구분 (A/B)

| 타입 | 할인율(J) | 배송비 | 적용 전략 |
|------|---------|--------|---------|

## 3. 전략별 파라미터

### 3-1. 최저가전략 — **A/B 타입 공통 노마진(S=0)**

| 항목 | 값 |
|---|---|
| C | 1.12 |
| H_min/max | 0.7 / **100** (B타입 수용, A는 H≈1 수준이라 영향 없음) |
| round_h | 3, **ceil 올림** (S≥0 보장) |
| bands (target_S) | `[[999999999, 0]]` — **전 구간 노마진 통일** |
| discount_rate | **A타입: 2% / B타입: 61%** (실행 시 인자) |
| shipping_absorbed | **OC API 상품별 배송비** 전달 (A: 0 / B: 해당 상품 배송비) |

> 2026-04-20 변경: 기존 A타입 13단계 음수 bands + max_h=3.5 → **A/B 공통 S=0 + max_h=100**.
> 이유: 복잡한 bands 대신 "손해 안 보게만" 단순 목표. 상품별 shipping 가변 대응.

### A타입(유배) 용도
네이버 가격비교탭 노출용. 할인후가 = 실 경쟁가격.

### B타입(무배) 용도
옥션/지마켓 **내부 검색순위** 상승용. 큰 할인율(61%)이 검색 알고리즘에서 가점 → 상위 노출.
등록가가 원가의 4~14배까지 부풀어도 의도된 (외부 가격비교엔 안 뿌리고 내부 알고리즘만 보는 용도).

### 3-2. 일반판매/광고전략

| 항목 | A/B 공통 |
|---|---|
| C | 1.5 |
| H_min/max | 0.8 / 5.0 |
| round_h | 3 |

V% 구간: 스마트스토어와 동일. B타입은 판매가에서 3,000원 배송비 흡수.

## 4. 공식 (pre_discount)

```
G  = 원가(A) × C + E
I  = G × H
L  = I × (1 - J)
N  = I × 16.5%          ← 수수료 (등록가 기준, pre_discount)
M  = 0원
O  = L - M - N - 배송비흡수
S  = O - 원가(A)
```

**coef:**
```
A타입 (J=2%):  coef = (1-0.02) - 0.165 = 0.815
B타입 (J=61%): coef = (1-0.61) - 0.165 = 0.225
```
