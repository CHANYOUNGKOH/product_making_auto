# ESM (옥션/지마켓) 가격 전략 정책

> SSOT. `docs/pricing/esm.md` 이 파일로 통합.
> 관련 설정: [DB_save/pricing_strategies.json](../../../DB_save/pricing_strategies.json) → `market_strategies.옥션` / `지마켓`

## 1. 기본 정책

| 항목 | 값 |
|------|---|
| 마켓수수료 | 16.5% |
| 수수료 기준 | **pre_discount** (할인전 등록가 기준) |
| 쿠폰(E) | 0원 |

## 2. 타입 구분 (A/B)

| 타입 | 할인율(J) | 배송비 | 적용 전략 |
|------|---------|--------|---------|
| A타입 (유배) | 2% | 구매자 부담 | 최저가 + 일반판매 + 광고 |
| B타입 (무배) | 61% | 판매자 흡수 3,000원 | 일반판매 + 광고 |

## 3. 전략별 파라미터

### 3-1. 최저가전략 — A타입만

| 항목 | 값 |
|---|---|
| C | 1.12 |
| H_min/max | 0.7 / 3.5 |
| round_h | 3, **ceil 올림** |
| bands (target_S 음수) | `≤300:-100, ≤1000:-200, ≤10000:-500, ≤50000:-1000, >150000:-1500` (13단계) |

### 3-2. 일반판매/광고전략

| 항목 | A/B 공통 |
|---|---|
| C | 1.5 |
| H_min/max | 0.8 / 5.0 |
| round_h | 3 |

V% 구간: 스마트스토어와 동일. B타입은 판매가에서 3,000원 배송비 흡수.

## 4. 공식 (pre_discount)

```
G  = 원가(A) × C + E
I  = G × H
L  = I × (1 - J)
N  = I × 16.5%          ← 수수료 (등록가 기준, pre_discount)
M  = 0원
O  = L - M - N - 배송비흡수
S  = O - 원가(A)
```

**coef:**
```
A타입 (J=2%):  coef = (1-0.02) - 0.165 = 0.815
B타입 (J=61%): coef = (1-0.61) - 0.165 = 0.225
```
