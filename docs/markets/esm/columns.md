# ESM 컬럼 정책

ESM 는 이셀러스 엑셀로 업로드 → [../esellers/columns.md](../esellers/columns.md) 에 정책 집결.

이 문서는 ESM 관점에서 이셀러스와 다른 규칙이 있을 때만 추가 기술.

## ESM 특이 규칙

- **타입 분기**: A(유배) / B(무배) 따라 배송비/쿠폰 J 필드 분기 → 가격엔진 결과 반영 필요
- **옵션 선택사항 타입**: 조합형 → ESM "선택사항" 포맷
- **카테고리 번호**: 옥션/지마켓 각각 다름 (한 엑셀에 둘 다 있을 수 있음)
- **ESM 추가구성 상세설명**, **ESM 광고홍보 상세설명**: 이셀러스 전용 컬럼
- **요약정보 상품군 코드**, **값1~값29**: 카테고리별 속성값 매트릭스
