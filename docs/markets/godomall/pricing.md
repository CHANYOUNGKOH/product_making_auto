> SSOT. `docs/pricing/godomall.md` 는 이 파일로 통합됨 (리다이렉트만 남김).
> 관련 설정: [DB_save/pricing_strategies.json](../../../DB_save/pricing_strategies.json) → `market_strategies.고도몰`

## 1. 마켓 기본 정책

| 항목 | 값 |
|------|---|
| 마켓수수료 | 4% |
| 수수료 기준 | post_discount (할인후 실결제금액 기준) |
| 쿠폰(E) | 50원 (고정) |
| 스마일캐시(P) | 0% |
| 플랫폼 할인율 | 없음 — brand_code 기반 자체 쿠폰으로 대체 |

## 2. 자체 쿠폰 정책 — brand_code 기반

[stores.md](stores.md#브랜드-코드--쿠폰-할인율-매핑) 참조. 4단계 쿠폰(001=35%, 002=28%, 003=18%, 004=10%).

### 전략별 J(할인율) 적용

| 전략 | J 적용 | brand_code |
|---|---|---|
| **최저가전략** (lowest_price) | **35% 단일 적용** (전 가격대 고정) | **"001" 일괄** |
| 일반판매전략 (normal_sale) | 가격대별 4단계 (35/28/18/10%) | 가격대별 001~004 |
| 광고전략 (cpc_ad) | 가격대별 4단계 (35/28/18/10%) | 가격대별 001~004 |

### 최저가전략 J=35% 단일의 의도

- **노출도 향상**: 할인후가가 검색결과에 노출 → 큰 할인율로 매력 ↑
- **노마진 전략**: target_S=0, ceil 올림으로 쿠폰 적용 시에도 영업이익 0원 이상 보장
- **쿠폰 미사용 주문에서 이익 회수**: 쿠폰 받지 않은 고객이 등록가로 결제 시 35% 마진이 통째로 남음

### 일반판매/광고전략의 4단계 J

| 단계 | 도매가 구간 | 쿠폰 할인율 J |
|------|----------------|------------|
| 1 | ≤ 5,000원 | 35% (brand 001) |
| 2 | 5,001 ~ 30,000원 | 28% (brand 002) |
| 3 | 30,001 ~ 100,000원 | 18% (brand 003) |
| 4 | > 100,000원 | 10% (brand 004) |

어드민 쿠폰 발급규칙이 brand_code별로 매핑 → 상품 등록 시 brand_code만 맞추면 자동 적용.

## 3. 전략별 파라미터

### 3-1. 최저가전략 (lowest_price)

| 항목 | 값 |
|------|---|
| 목표 지표 | absolute_s (영업이익 0원) |
| 마진배수 C | 1.12 |
| H 최소 | 0.8 |
| H 최대 | 3.5 |
| H 반올림 | 3자리 **ceil (올림)** |
| discount_bands | `[[999999999, 35]]` — 35% 단일 |
| target_S bands | `[[999999999, 0]]` — 전 구간 0원 |

> `round_mode=ceil`: H 올림으로 영업이익이 항상 0 이상 보장.

|-------|---|---|---------|----------|
| 1,000 | 35% | 1.439 | 1,684 | +1원 |
| 10,000 | 35% | 1.432 | 16,110 | +3원 |
| 50,000 | 35% | 1.432 | 80,264 | +34원 |
| 100,000 | 35% | 1.431 | 160,344 | +4원 |
| 500,000 | 35% | 1.431 | 801,432 | +43원 |

| 항목 | 값 |
|------|---|
| 목표 지표 | v_percent (매출대비 V%) |

### 3-3. 광고전략 (cpc_ad)

일반판매와 C/H 동일, V% 구간만 다름 (모든 구간에서 normal_sale보다 +2~5%).

## 4. 공식 (post_discount)

```
G  = 원가(A) × C + E
I  = G × H
L  = I × (1 - J)
N  = L × 4%
M  = E = 50원
O  = L - M - N
S  = O - 원가(A)
V% = S / L × 100
```

**최저가전략 H 역산:**
```
coef = (1 - J) × (1 - 0.04)
H_raw = (target_S + E + 원가) / (G × coef)
H = ceil(H_raw, 3자리)
```

**일반/광고전략 H 역산:**
```
coef_v = (1 - J) × (1 - 0.04 - V%)
H_raw  = (E + 원가) / (G × coef_v)
```
