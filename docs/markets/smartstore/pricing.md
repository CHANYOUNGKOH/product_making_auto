## 3. 공식 (post_discount)

```
G  = 원가(A) × C + E
I  = G × H
L  = I × (1 - 0.50)           ← 플랫폼 할인 무조건
N  = L × 6.5%                 ← 마켓수수료
Q  = L × 15%                  ← 다운로드 쿠폰 (worst-case 가정, 실제는 고객 선택)
M  = 100원                    ← 플랫폼 쿠폰
O  = L - M - N - Q
S  = O - 원가(A)
V% = S / L × 100
```

**coef (worst-case):**
```
coef = (1 - 0.50) × (1 - 0.065 - 0.15) = 0.3925
```

**최저가전략 H 역산:**
```
H_raw = (target_S + 100 + 원가) / (G × 0.3925)
```
